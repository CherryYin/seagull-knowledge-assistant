# Organize Recent Imports

Default to the last 7 days unless the user provides a narrower filter.

## Workflow
1. List or search recently imported sources and notes.
2. Group related items into meaningful topics.
3. Identify duplicates and near-duplicates.
4. Suggest missing links between sources, notes, memories, and wiki pages.
5. Identify missing notes and wiki refresh candidates.
6. Present proposed changes without applying them.

## Duplicates
## Suggested Links
## Suggested Updates
## Changes To Apply

Reference object IDs when available. The future save target is a note, only after explicit confirmation.
