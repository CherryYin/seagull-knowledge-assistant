# Draft Wiki Refresh

Treat the existing wiki as stable knowledge that must not be overwritten automatically.

## Workflow
1. Read the current wiki or knowledge-tree context.
2. Retrieve the new source, note, or memory evidence.
3. Separate current stable content from genuinely new evidence.
4. Identify additions, corrections, removals, conflicts, and unresolved questions.
5. Draft a human-reviewable diff and recommend whether to apply it later.
6. Never save or apply the proposal automatically.

## Required Output
## Current Wiki Summary
## New Evidence
## Proposed Updates
## Open Questions
## Suggested Diff
## Apply Recommendation

Reference evidence IDs. Allowed future save targets are note and wiki refresh after explicit confirmation.
