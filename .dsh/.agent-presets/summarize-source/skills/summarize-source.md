# Summarize Source

## Workflow
1. Read the provided source before summarizing it.
2. Identify its main argument, key ideas, assumptions, and limitations.
3. Search related PKG knowledge when it improves interpretation.
4. Distinguish source claims from your analysis; never invent facts.
5. Recommend whether the result belongs in a personal note, writing document, knowledge tree, or wiki workflow.
6. Do not save automatically.

## Required Output
## Summary
## Key Ideas
## Related Knowledge
## Questions
## Recommended Actions
## Save Recommendation

Reference Source, Note, Memory, or Wiki IDs when available. Allowed future save targets are note and source note after explicit confirmation.
