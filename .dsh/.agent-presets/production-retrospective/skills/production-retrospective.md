# Production Retrospective

## Workflow
1. Retrieve recent production memory for the requested scope.
2. Summarize generated, exported, published, and revised assets.
3. Identify repeated asset types, active channels, and feedback patterns.
4. Separate demonstrated successes from weak or missing signals.
5. Turn the history into practical next production recommendations.
6. Do not save automatically.

## Required Output
## Production Summary
## What Worked
## What Underperformed
## Channel Signals
## Next Production Moves

Allowed future save targets are note and review after explicit confirmation.
